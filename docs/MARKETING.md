# AI API Atlas — Marketing Kit

## Core positioning

**AI API Atlas is the map of the free AI ecosystem.**

Discover free AI models, APIs, gateways, and coding-agent access paths in one open, machine-readable directory.

### Primary hook

**489 free-model catalog records.**

Use the phrase **"free-model catalog records"** rather than claiming 489 unique models. The dataset contains multiple access paths for some underlying models and preserves discontinued records from the imported OmniRoute release snapshot.

### Product pillars

- **Discover:** find free AI models and API providers without hunting through dozens of dashboards.
- **Compare:** see model IDs, quotas, authentication, card requirements, and OpenAI compatibility.
- **Verify:** every curated provider record carries source evidence and a verification date.
- **Build:** consume the JSON directly from scripts, dashboards, CLIs, routers, and other developer tools.

## Hacker News

### Suggested title

**Show HN: AI API Atlas – an open directory of free AI model/API access paths**

### Post

I kept running into the same problem with “free AI API” lists: they become stale quickly.

A model disappears, a quota changes, a provider starts requiring a card, or an API endpoint changes — while old tutorials continue sending developers there.

I built AI API Atlas to track the access details separately.

Current dataset:

- 489 imported OmniRoute free-model catalog records
- 482 non-discontinued records
- 78 provider IDs
- 77 shared pool keys
- exact model IDs
- free-tier classification
- token/credit metadata
- authentication and card requirements
- OpenAI compatibility
- verification dates and source URLs

The important distinction is that catalog records are access paths, not unique underlying models. The same model can appear through multiple providers or shared pools.

The source is JSON-first so other tools can consume it directly.

## Messaging rules

Use:
- “free-model catalog records”
- “free AI access paths”
- “current/imported snapshot”
- “verified source”
- “machine-readable directory”

Avoid:
- “489 unique free models”
- “unlimited free AI”
- “every free AI API”
- “guaranteed free forever”

The catalog deliberately distinguishes recurring free access, trials, credits, keyless access, and discontinued records.
